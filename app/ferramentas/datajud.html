⚙️ Ponte (se der erro de conexão)

A API do CNJ não deixa ser chamada direto do celular. No programa do PC funciona sozinho. No celular, publique o jurídico no Netlify pelo GitHub (a ponte netlify/functions/datajud.js já vem no projeto) — ou cole aqui o endereço da sua ponte:

A chave usada é a chave pública que o próprio CNJ divulga (igual para todos). Se o CNJ trocar, ponha a nova no Netlify como DATAJUD_KEY.

Abre a pesquisa oficial de cada tribunal com os seus termos. Os termos também vão copiados, caso o site peça para colar. Confira sempre o inteiro teor e o número do julgado na fonte.
